# 模型 A/B 实测记录（2026-11-03）

环境：Medium_Phone_API_37.0 AVD（x86_64 / SwiftShader / Android 17）。
性质：**链路验证，不作为性能验收结论**。

### QOperator A/B（2026-11-03）

| 项 | QDQ（默认） | QOperator（候选） |
|---|---|---|
| 体积 | 78.2 MB | 76.8 MB |
| 文件 | `tools/model-ab/out/schp_atr_int8.onnx` | `tools/model-ab/out/schp_atr_int8_qoperator.onnx` |
| XNNPACK | session 创建失败 → CPU EP | session 创建成功 |
| 模拟器首次加载+解析 | 约 32.0 s | 约 49.2 s |
| 结论 | **当前默认** | 暂不采用 |

QOperator 能启用 XNNPACK，但在 x86_64/SwiftShader 模拟器上反而更慢；不能据此下真机结论。QOperator 模型保留在 `tools/model-ab/out/`，待 arm64 真机复测后再决定是否替换。

### NCNN

暂未执行：SCHP 是 ResNet101 + CE2P 复合结构，直接转 NCNN 需要额外算子/后处理适配，当前收益不确定；先以 QOperator 作为低风险候选。若真机 QOperator 仍不达标，再启动 NCNN/PNNX 评估。

## M3 模型矩阵冻结

- 人像 matting：MODNet ONNX，512（低端可选 384）。
- 服装解析：SCHP-ATR INT8，512，CPU EP fallback。
- 场景/天空/主体摘要：`CanvasAnalyzer` 启发式（颜色/亮度/皮肤显著性），不引入专用开放词表检测或天空分割模型。
- U3/U4：`RegionSelector` 用户框选兜底；`CanvasDigest` 的对象置信度固定为 0.5，低于自动规划门槛 0.6，确保不会误自动定位。
- 意图：DeepSeek 客户端 + 离线规则网关；规则样本 375 条通过 ≥95% 门槛。

## 真实设备

当前没有连接真机；三档设备型号仍需用户填入 `docs/adr/0001-m0-decisions.md`。

## 决策建议

1. M2 默认 MODNet 512 保证发丝质量；低端机可提供 384 快速档。
2. XNNPACK 首次加载较慢，应复用 session，避免每次重建。
3. 背景合成中的 Reinhard LAB 在模拟器上约 4.8 s，需在真机验证；不达标则只对降采样图做迁移再上采样。
4. SCHP INT8 已可用，但 QDQ 只能走 CPU EP；下一步尝试 QOperator 或 NCNN 以恢复 XNNPACK/NPU 加速。
5. U8 功能链路已通过真实人像测试；画质仍需更多真实服装样张与真机验收。
